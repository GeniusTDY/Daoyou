差异说明（仅说明存在差异的目录功能）

仅 我的仓库 有的目录

这些目录在 ChurchTao/Daoyou 中不存在。

deploy/离线/单机一键部署方案：offline/app（离线后端入口与联机战斗结算器）、offline/config（NATS 配置）、offline/web（离线前端静态构建）及 start/stop/gen-secrets 启停与密钥生成脚本。
public/fonts/自带的字体资源（站酷小薇、马善政楷体等）。ChurchTao 未将该目录入库。
仅 ChurchTao/Daoyou 有的目录

这些目录在我的仓库中不存在。

sponsorkit/赞助商自动化素材生成（赞助者头像/感谢图）。
scripts/fixtures/固定示例数据，供演示与测试使用。
public/assets/battle/realtime/ui/实时联机战斗 UI 素材（resources/unit）。
public/assets/sect/{mining,onboarding,sweep}/宗门采矿、引导、扫荡玩法素材。
react-app/components/feature/大型功能组件层：把各玩法 UI 按 feature 拆分为数十个包（alchemy、battle、creation、craft、sect、map、world-chat…）。
react-app/routes/**game/**：arena、auction、battle、bet-battle、black-market、body-cultivation、community、craft、create、dungeon、enlightenment、fate-reshape、identity-reshape、inn、inventory、mail、map、market、marrow-wash、merit-ledger、rankings、redeem、reincarnate、retreat、sect(30+)、settings、skills、spirit-field、tasks、techniques、tianjiao-vault、tower、training-room、world-chat 等；admin/**：后台各页面；login/signup/forgot/reset-password：鉴权流程独立路由。
server/lib/repositories/数据库仓储层，集中封装 Drizzle 持久化查询。
server/lib/drizzle/Drizzle 数据访问入口。
server/lib/jobs/后台任务 / 定时任务模块。
server/lib/http/HTTP 客户端工具。
server/lib/llm/LLM 集成层（统一 provider 调用）。
server/lib/{mq,nats}/消息队列与 NATS 消息总线集成（领域事件发布/订阅）。
server/lib/redeem/兑换码模块。
server/lib/sponsorship/赞助管理。
server/lib/template/模板渲染（邮件/公告等）。
server/lib/admin/ · routes/api/admin · api/cultivator管理后台能力与 API 按业务域再分组的二级路由。
server/lib/dungeon/reward/副本奖励逻辑独立成模块。
shared/engine/battle-v5/**战斗引擎深度模块化：abilities、adapters、buffs、core、effects、factories、match、persistence、presentation、round、runtime、setup、systems、units 及 tests —— 本项目仅一个 index。
shared/engine/creation-v2/**炼化/制作引擎深度模块化：affixes、analysis、composers、core、handlers、models、persistence、resolvers、rules、services、validation 及 tests —— 本项目为扁平文件。
shared/engine/material/材料引擎（含 creation/data）。
shared/engine/sect/宗门内容引擎：content 下 jiujie/lingxiao/tianyan/wuxiang/youdu 五大宗门玩法，core 下 authoring、compilation、domain、mining、organization、plugin、presentation、progression、runtime、sweep、validation，另有 testing。
shared/engine/{cultivation/exp-gain-strategies, cultivator/creation, shared/tag-domain}经验成长策略、角色创建域、共享标签域等细分引擎。
两者都有、但内部组织结构不同的目录

同名目录，但内部划分方式不同。

react-app/routes/game我的仓库：单一 game/route + 场景(handle scene)机制承载全部玩法；ChurchTao：为每个玩法建独立路由目录。
react-app/components我的仓库：ui/layout/game-shell 公共组件 + 少量 func/；ChurchTao：额外引入大规模 feature/** 组件归集。
server/lib/services我的仓库：扁平单个 .ts 服务文件集合；ChurchTao：按业务领域分子目录（alchemy、black-market、cultivator、resource、sect-organization、spirit-field）。
shared/engine我的仓库：浅层/扁平（battle-v5 仅 index、creation-v2 单文件等）；ChurchTao：深度模块化并新增 material、sect-content、tag-domain 等子引擎。
public/assets/sect我的仓库：仅各宗门整体地图图集；ChurchTao：增细分玩法素材目录。
说明：对比基于两侧仓库目录（tree），不含文件内容比较；我的仓库取自当前工作区磁盘，ChurchTao/Daoyou 取自 GitHub master 分支目录树。
