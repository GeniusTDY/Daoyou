结论

本地仓库是上游的一个「离线 / 独立部署」定制分支

· 新增 离线一键部署（deploy/），内置 bun / redis / nats 与构建产物，可在无外网环境下自启。

· 把 Docker 与 compose 收进 docker/ 和 scripts/，并新增 battle-worker 构建与蓝绿发布脚本。

· 移除了赞助运营相关（sponsorkit / SPONSORING / SPONSORS / .env.example）。

若要同步上游，注意 diff 位置差异：
root Dockerfile → docker/Dockerfile.app · root docker-compose*.yml → scripts/ · 并考虑补回 .env.example。
