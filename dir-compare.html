sponsorkit/仅远程
仅列出“两侧存在差异”的目录。仅本地 = 本地有而远端无；仅远程 = 远端有而本地无。
仅本地独有 deploy/ —— 一键离线部署方案（最主要差异）
deploy/offline/bin
打包好的离线运行环境二进制：bun（运行时）、nats（消息队列）、PostgreSQL（含完整 include/lib/share 头文件、扩展与时区数据）、redis。
deploy/offline/config
离线部署运行配置（如 nats-server.conf）。
deploy/offline/app · web
打包产物：app 为后端服务，web 为前端静态站（含通用 assets、字体、图标等资源）。
deploy/offline/migrations
随包分发的 drizzle 迁移快照（drizzle / drizzle-auth 两套），用于离线环境建表。
deploy/offline + 配套脚本
连同 start / stop / gen-secrets / migrate 等启停与密钥生成脚本（bat / ps1 / sh），组成开箱即用的整套离线一键部署包。GitHub 端无此目录。
仅本地独有 public/fonts —— 前端字体资源
public/fonts
默认定制字体：LXGW 屏显文楷（正文）与马善政毛笔行书（Logo / 标题），本地单独维护。
仅远端独有 功德 & 赞助（merit / sponsorship）模块
sponsorkit
GitHub Sponsors 自动生成赞助图的工具资源与配置。
src/server/lib/sponsorship
服务端赞助业务（记录、核对等）。
src/react-app/routes/admin/sponsorship
管理后台赞助管理页面。
src/react-app/components/feature/merit
功德玩法前端组件。
src/react-app/routes/game/merit-ledger
游戏内功德账本页面（含其 components 私有组件）。
仅远端独有 认证扩展路由（邮箱 / 密码体系）
routes/forgot-password · reset-password
忘记密码与重置密码页面。
routes/login/email · password · verify
登录流程拆分为“邮箱 / 密码 / 验证”三个子步骤。
routes/signup/password
注册流程中的设置密码子页。
（对应本地路径）
以上为仅远端新增的认证子路由；本地对应 login / signup 未按邮箱、密码、验证拆分。
仅远端独有 共享引擎测试套件（大量新增）
src/shared/engine/battle-v5/tests
战斗引擎 v5 测试，含 core / effects / systems / setup / units / integration / presentation 等子目录。
src/shared/engine/creation-v2/tests
炼制/造物引擎 v2 测试，含 affixes / analysis / config / rules / persistence / integration / helpers 等子目录。
src/shared/engine/sect/content/…/tests
五大宗门内容测试：jiujie / lingxiao / tianyan / wuxiang / youdu。
src/shared/engine/sect/core/tests
宗门核心引擎测试。
src/shared/engine/sect/testing
宗门引擎测试基础设施：architecture（结构检查）与 fixtures（夹具）。
src/server/lib/services/sect-organization/testing
宗门组织服务（服务端）测试目录。
scripts/fixtures
脚本运行所用的测试夹具 / 样例数据目录。
一句话总结
本地相对远程多出整套离线部署包（deploy/offline，含打包好的运行环境二进制、迁移与产物）以及字体目录；远程相对本地多出功德 / 赞助模块、邮箱密码认证子路由，以及大量共享引擎与宗门测试套件。核心业务目录（src/react-app、src/server、src/shared 的主要子目录）结构调整一致。
